This Verilog design implements a finite state machine (FSM)–based four-way traffic light controller for an intersection with West, North, East, and South directions. Each direction is provided with signals for green (straight, left, right), yellow, and red lights. The controller cycles through eight states (s0–s7), where each state corresponds to either a green or yellow phase for one direction. A counter keeps track of how long the controller stays in a given state, with the green phase lasting for eight clock cycles and the yellow phase lasting for two clock cycles. The FSM transitions from green to yellow for the active direction and then moves to the next direction in sequence, creating a round-robin schedule: West → North → East → South → back to West. At reset, the FSM starts at state s0 with West green active.

In operation, the outputs are set such that only the active direction gets green or yellow while the others remain red by default. For example, in state s0, the West signals are green (straight, right, and left), while in s1, West switches to yellow with left still active. The same pattern is repeated for North (s2, s3), East (s4, s5), and South (s6, s7). An additional feature is that while one direction has green or yellow, the next direction’s left turn light is enabled in parallel, improving traffic flow efficiency. Once the yellow phase for South ends, the FSM loops back to s0 and the sequence repeats continuously. This design ensures a structured and predictable cycle of traffic light signals, with clear timing and priority given to straight, right, and left movements in each direction.
